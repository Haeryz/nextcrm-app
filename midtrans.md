# BI SNAP Credentials
BI SNAP requires specific credentials to integrate with compliant payment methods and disbursement APIs. To generate the credentials, start by registering your merchant public key and IP address by clicking the button below. If you want to add extra payment methods like payment cards, combine it with Core API. Find detail instructions in the Midtrans API Documentation (https://docs.midtrans.com/reference/getting-started-1).
